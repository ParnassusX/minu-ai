Browser Console Commands

Open browser developer tools (F12) and run these commands:

Check for Generator V2:

document.querySelector('[data-testid="generator-v2"]') ? 'Generator V2 Found' : 'Generator V2 NOT Found'

Check Page Title:

document.title

Check Main Heading:

document.querySelector('h1')?.textContent

Check All Headings:

Array.from(document.querySelectorAll('h1, h2, h3')).map(h => h.textContent)

Check for Navigation:

document.querySelector('.nav-responsive') ? 'Navigation Found' : 'Navigation NOT Found'

Check for Mode Selector:

document.querySelector('[data-testid="mode-selector"]') ? 'Mode Selector Found' : 'Mode Selector NOT Found'

Check Current URL:

window.location.href

Check Environment Variables:

console.log('NODE_ENV:', process?.env?.NODE_ENV || 'Not available')

Full Interface Analysis:

{
  title: document.title,
  url: window.location.href,
  mainHeading: document.querySelector('h1')?.textContent,
  allHeadings: Array.from(document.querySelectorAll('h1, h2, h3')).map(h => h.textContent),
  hasGeneratorV2: !!document.querySelector('[data-testid="generator-v2"]'),
  hasNavigation: !!document.querySelector('.nav-responsive'),
  hasModeSelector: !!document.querySelector('[data-testid="mode-selector"]'),
  buttonTexts: Array.from(document.querySelectorAll('button')).map(b => b.textContent?.trim()).filter(Boolean),
  inputCount: document.querySelectorAll('input, textarea, select').length,
  isLoginPage: window.location.href.includes('/auth/login'),
  bodyClasses: document.body.className,
  reactRoot: !!document.querySelector('#__next')
}

Troubleshooting Steps

  1. Clear Browser Cache: Ctrl+Shift+R (hard reload)
  2. Try Incognito Mode: Open generator in private/incognito window
  3. Check Network Tab: Look for failed requests or redirects
  4. Check Console: Look for JavaScript errors
  5. Verify Server: Ensure development server is running on port 4000
  6. Test Different Browsers: Try Chrome, Firefox, Edge
  7. Check Authentication: Try logging in first, then accessing generator
